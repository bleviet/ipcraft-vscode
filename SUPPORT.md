# Support

This project is maintained by a small team on a best-effort basis. Use the
right channel below so your request reaches the right place and gets a
useful response.

## Usage questions

"How do I do X in IPCraft?" or "why does this behave this way?"

- Check the [documentation](https://bleviet.github.io/ipcraft-vscode/) first
  — most workflows (creating an IP core, memory-map editing, generation,
  builds, imports) have a how-to guide.
- If the docs don't answer it, open an issue using the **Question / support**
  option in the
  [issue template chooser](https://github.com/bleviet/ipcraft-vscode/issues/new/choose).
  Include your IPCraft version, VS Code version, and what you already tried.

## Bug reports

Something works differently than documented, or crashes.

- Search [existing issues](https://github.com/bleviet/ipcraft-vscode/issues)
  first to avoid duplicates.
- Open a new issue using the **Bug report** template. Include reproduction
  steps, the smallest `.ip.yml`/`.mm.yml` spec that reproduces it, and the
  IPCraft/VS Code versions.

## Feature requests

- Open an issue using the **Feature request** template describing the
  problem you're trying to solve, not just the requested implementation —
  it's easier to evaluate and may already have a supported path.

## Security reports

**Do not open a public issue for a security vulnerability.** Follow the
private reporting process in [SECURITY.md](SECURITY.md).

## Contributing

If you want to fix a bug or implement a feature yourself, see
[CONTRIBUTING.md](CONTRIBUTING.md) for setup, coding conventions, and test
expectations.
