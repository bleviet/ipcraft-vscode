UI/UX Proposal: Navigating Huge Block Designs & Qsys Systems (10+ Subsystems, 1,000+ Connections)
  • 1. Semantic Zoom & Pin-Group Folding (Auto / Arch / Compact / Full): High-pin-count blocks (e.g. 28-port smartconnect, 16-bit xlconcat, 8-channel DMA/ADC) automatically fold repetitive bus arrays into expandable rows (▸ M00..M27_AXI [28]), shrinking block height by 70%. At low zoom (Arch), blocks render as high-contrast Architectural Cards with interface summary pills and inline subsystem stage previews.
  • 2. Smart Bus Bundling & Collision-Free Routing: Parallel nets between the same block pair merge into a single trunk cable with a clickable badge (×12 AXI, ×8 AXIS, ×16 IRQ) that expands on selection. Vertical wire channels use interval-packed lanes so wires never stack on top of each other.
  • 3. Neighborhood Focus (1-Hop / 2-Hop Slice) & Path Tracer: Select any block and click Isolate to slice a 1,500-connection system down to its 1-hop or 2-hop data/control neighborhood (ignoring global clock/reset fanout). Use Trace path (From → To) to highlight and isolate the shortest multi-hop signal chain between any two endpoints.
  • 4. Subsystem Adjacency Matrix, World Minimap & Layer Filtering: Switch to Matrix for an N×N subsystem connectivity overview (click any cell to isolate that interface pair), pan via the bottom-right World Minimap (with search/CDC heat dots), and click Legend chips to toggle or solo wire categories.
Proposal for #243 & #245: Clock/Reset Domains & Unconnected Pins (offline, no Vivado)
  • Clock domain = one clock source pin and every clock pin its nets reach across hierarchies. Source frequencies come from declarative rules (PCW_FPGAn_PERIPHERAL_FREQMHZ, PSU__CRL_APB__PLn_REF_CTRL__FREQMHZ, CLKOUTn_REQUESTED_OUT_FREQ, CONFIG.FREQ_HZ, clockFrequency).
  • CDC & RDC checks: AXI-MM / AXI4-Stream nets and reset sinks whose two ends sit on different domains without a synchronizer are flagged and navigable from the Clocks tab.
  • Unconnected pins (#245): Checked on blocks with known pin lists (.ip.yml, HDL module, declared hierarchy/external ports); undriven inputs are highlighted in warning color and unused outputs muted.
