# Episode 5: Write the user logic

This is the project at the start of the episode. See the [checkpoint overview](../README.md) for how to use it.

## What is here

Run **IPCraft: Scaffold Project (RTL + EDA packaging + Testbench)** with VHDL, then open `rtl/led_controller_avmm_core.vhd`.
