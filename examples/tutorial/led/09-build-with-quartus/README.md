# Episode 9: Build with Quartus

This is the project at the start of the episode. See the [checkpoint overview](../README.md) for how to use it.

## What is here

Checkpoint 08, plus the DE10-Nano top level in `altera/hdl/`, the Quartus project scripts and Makefile in `altera/quartus/`, and the Nios II software in `software/`.

## First step

Run **IPCraft: Scaffold Project (RTL + EDA packaging + Testbench)** with VHDL and keep the core, then build with `make` in `altera/quartus/`. The Makefile runs Quartus in Docker.
