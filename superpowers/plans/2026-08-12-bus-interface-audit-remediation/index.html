    Bus Interface Audit Remediation Implementation Plan¶

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Remove the confirmed audit defects while preserving vendor behavior, authored document state, and the existing V-3/V-4 revision protocol.

    Architecture: Vendor parsers adapt XML/Tcl syntax into pure bus-contract inputs. Shared contract modules own reusable reconciliation, typed metadata, and declarative-contract policy. Vendor generators emit resolved standard metadata for tools and authored-only IPCraft mirror metadata for lossless re-import.

    Tech Stack: TypeScript, Jest with config/jest.config.js, integration Jest with config/jest.integration.js, IP-XACT XML, Quartus _hw.tcl, YAML bus contracts.
